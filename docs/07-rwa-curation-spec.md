# 精选 RWA 项目规格

## 1. 页面结构

每个精选 RWA listing 至少展示：

- 项目名称和资产类型。
- 发行方。
- 托管/服务方。
- 辖区和限制地区。
- Token 地址和 Pool 地址。
- 法律文件、审计/评估文件和证明 Hash。
- 发行量、状态、审核时间和审核者。
- 风险披露。

## 2. 审核状态

| 状态 | 含义 | Market 展示 |
| --- | --- | --- |
| Submitted | 已收到资料 | 不进入精选 |
| Review | 正在人工审核 | 可在审核队列查看 |
| Approved | 审核通过，可发布 | 可进入精选候选 |
| Listed | 已公开展示 | 出现在 Curated Market |
| Paused | 暂停展示或交易入口 | 保留原因 |
| Rejected | 未通过 | 不进入公开精选 |

## 3. 不允许的表达

- “Custos 保证底层资产真实”。
- “Custos 保证兑付/赎回”。
- “已审核所以没有风险”。
- “固定收益”“保本”“官方股票/黄金”。
- 将 demo listing、测试网 Token 或参考价格写成可兑换资产。

## 4. 第一阶段审核方式

Grant demo 阶段采用人工白名单和后端状态记录，管理员动作需要后续接入真实认证与审计日志。没有权限系统前，任何审核接口只能作为本地演示，不应直接部署为公开生产管理入口。
